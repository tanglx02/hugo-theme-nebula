> This page renders `params.home.layout = "hero"` for real.

## Enable

```toml
[params.home]
  layout = "hero"
```

## Traits

- Taller, **full-width hero** on top
- **No sidebar**; the post list spans the full width
- Falls back to text cards when there is no cover / no featured post
