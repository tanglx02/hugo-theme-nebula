本页是**功能二（文章阅读体验）**的实机演示。页面右侧目录、正文阅读进度条、
右下角返回顶部按钮、左下角专注模式按钮都可直接操作；打印预览（Ctrl/Cmd + P）
可见纸面排版。

## 一、阅读进度条

屏幕顶部那条细线就是进度条。它按**正文阅读区**（`.post-content`）计算，
而不是整篇文档——因此当正文读到最后一段时进度条即满，
不会被页脚、相关文章、评论区继续"拉长"。

- 起点：正文顶部与视口顶端对齐时；
- 终点：正文底部抵达视口底部时；
- 正文比视口还短时直接记满，不会卡在 0% 或冲出 100%。

## 二、返回顶部

下滚超过 400px 后，右下角出现圆形按钮。它是原生 `<button>`，
可用 Tab 聚焦、Enter / Space 触发；系统开启"减少动态效果"时改为瞬时跳转。

## 三、专注模式

点击左下角「专注模式」按钮（或按 Enter）后：

- 保留**正文**与**站点头部导航**（随时可以离开当前页）；
- 收起侧栏、目录、标签、上下篇、相关文章、系列、分享、评论等次要区块；
- 状态写入 localStorage，刷新后保持；
- 按 Escape 退出。

> 专注模式**不会**隐藏正文，也**不会**让页面失去导航 —— 这两条是硬约束，
> 否则读者会被困在模式里出不来。

## 四、打印样式

按 Ctrl/Cmd + P 打开打印预览，会看到：

| 元素 | 打印时的处理 |
| --- | --- |
| 进度条 / 返回顶部 / 专注按钮 | 移除 |
| 页头 / 页脚 / 侧栏 | 移除 |
| 分享 / 上下篇 / 相关文章 / 评论 | 移除 |
| 正文 | 保留，白底黑字、纸面字号与行高 |
| 正文内 http(s) 外链 | 附上完整 URL（打印后不可点击，URL 是唯一线索） |
| 代码块 | 自动换行，不横向溢出纸面 |
| 图片 / 表格 | 尽量不跨页裁切 |

## 五、如何配置

站点级默认值（`hugo.toml`）：

```toml
[params.reading]
  progressBar = true    # 阅读进度条，默认 true
  backToTop   = true    # 返回顶部，默认 true
  focusMode   = false   # 专注模式入口，默认 false（新功能默认关闭）
```

文章级覆盖（Front Matter，只影响当前文章）：

```yaml
---
showProgress: false    # 本页不显示进度条
showBackToTop: false   # 本页不显示返回顶部
showFocusMode: true    # 本页显示专注模式按钮
---
```

<details>
<summary>为什么这里的 false 一定生效？</summary>

Hugo 模板里常见的 `.Params.flag | default true` 写法在 `flag: false` 时
**会返回 true**——`default` 只判断零值，而 `false` 恰好是 bool 的零值。
本主题统一改用内部 `util/bool-param.html`（基于 `isset` 语义），
显式 `false` 不再被吞掉。这条修复同时覆盖 `showDate` / `toc` / `comments` /
`breadcrumb` 等历史开关。

</details>
