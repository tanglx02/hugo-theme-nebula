## 2. 产品缺陷：根因、修改文件、验证

### BUG-R2-003 · 头像回退失效
- **根因**：`util/rel-url.html` 是通用路径规范化器，把空串 / `/` 视为站点根（对 `href="/"` 正确，但对 `<img src>` 是无效值），于是未配置头像时渲染出 `<img src="/">` 破损图，字母头像回退成为死代码。
- **修改**：新增 `layouts/partials/util/avatar-url.html`（空/纯空白/危险 scheme/解析成站点根 → 输出空串）；`layouts/partials/post-card.html`、`layouts/partials/sidebar.html` 改用它。
- **验证**（`r2_jsld_av.py`，Hugo 0.167.0）：7 场景（unset/empty/blank/root/js/valid）全部 `rc=0`，`src` 等于站点根的出现次数 **0**。

### BUG-R2-001 · contentLimit 截断越界
- **根因**：`layouts/_default/index.json` 用字节 `len` 判断长度，却把该字节数当 rune 结束索引传给 `slicestr`；中文正文 `rune < limit < 字节` 时越界 panic，终止**整站**构建。
- **修改**：改走 `partial "util/slice-runes.html"`（内部 `countrunes` 判定，绝不越界）。
- **验证**：五版本（0.128.0/0.148.0/0.162.0/0.166.0/0.167.0）`contentLimit=3000` + 中文正文均 `rc=0`、`panic=False`；高版本按门限回退/分片行为符合预期。

### BUG-R2-002 / DOC-R2-001 · `resources.Publish` 门限 0.167 → 0.166
- **根因**：`resources.Publish` 实际自 **Hugo 0.166.0** 提供，代码与文档误写 0.167。
- **修改**：`layouts/_default/index.json`（能力探测用语义化数值比较 + `errorf`/`warnf` 提示）、`theme.toml`、`README.md`、`docs/稳定基线.md`、`tools/check_search_modes.py`、`CHANGELOG.md` 全部统一为 **0.166**。
- **验证**：`check_search_modes.py` 14/14 PASS（含旧版本显式 shard 明确报错、auto 有界回退）。

### BUG-R2-004 · 关闭弹窗滚动跳动
- **根因**：`createModalA11y` 的 `close()` 与移动菜单 Escape 分支归还焦点时未用 `preventScroll`；Chromium/WebKit 会因 `focus()` 把文档滚回触发元素的静态位置。
- **修改**：`assets/js/main.js` 改用 `focus({ preventScroll: true })`（保留焦点可访问性）。
- **验证**（决定性）：关闭后 `scrollY` 相对打开位置漂移——
  - **修复后**：chromium / firefox / webkit = **0px**；
  - **模拟回归**（注入无 `preventScroll`）：chromium **−358px**、webkit **−65px**。
  - 新增断言 **2d** 并证明可证伪（见 §5）。

### BUG-R2-005 · JSON-LD `author.name: null`
- **根因**：无作者时仍构造 `"author":{"@type":"Person","name":null}`（schema.org 要求 `Person.name` 为字符串）。
- **修改**：`layouts/partials/head.html` 改为**无作者即省略 `author` 字段**，不虚构姓名。
- **验证**：四场景——无作者/空作者 → `author` 字段 **ABSENT**；站点级/文章级作者 → 字符串值；全站 `name:null` = **0**。

### BUG-P3-006 · 44×44 触控目标
- **修改**：`assets/css/main.css` 在 `≤900px` 用 `min-*` 提升 `.search-trigger`、`.brand` 到 44×44（避免窄视口横向溢出）。
- **范围**：搜索按钮与品牌入口已达标；`chip` 标签与正文内联链接未放大（AA 24×24 / 内联豁免，**未达** AAA），已如实记录。

## 9. 剩余风险与已记录限制

1. **`contentLimit` 为「软上限」**：经 partial 传参后 Hugo 对传入字符串的 rune 计数与直接 `countrunes` 存在**有界偏差**（实测 `limit=3000`、中文 + HTML 实体正文出现 3448 条目）。偏差**只会偏长**（绝不因多截丢失正文）、不 panic。已记入 README「已知限制」。若需精确硬截断，建议显式下调 `contentLimit` 留余量。
2. **BUG-P3-004**：静态/外链图片 `width/height` 构建期不可知，实测 CLS=0，慢速网络仍有轻微抖动风险。
3. **SRI / CSP**：保留可选设计，需使用者在托管层配置，主题不代为承担第三方资源被篡改风险。
4. **触控**：`chip` 24px、正文内联链接未放大，满足 AA 但未达 AAA 44×44。
