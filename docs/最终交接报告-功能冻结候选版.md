### 6.1 三浏览器审计范围（如实登记 A / B / C）

**A. 三引擎套件是否全部执行并通过？**

- CI `browser-tests` matrix 为 `browser: [chromium, firefox, webkit]` → **3 个 job 全部执行**；
  每个 job 跑**同一套门禁脚本**，但其中 `interactions.py` 的内部子集**按引擎不同**（见下 B 表）。
- **本轮本地实跑结果**：chromium / firefox / webkit 各 **12/12 PASS**（audit、interactions、copy、
  lightbox、search_modal、search_edge、highlight、shard、modal_scroll、contrast、overflow、baseurl）。
  ⚠ 这是**开发方自测**；本环境**不含历史 CI run 日志**，故**不能**据此声称"某次 CI 绿灯"——
  结论来自 workflow 配置 + 本地复跑。

**B. 各引擎实际跑了哪些视口 / 交互 / 搜索 / 复制 / 灯箱 / 模态框滚动 / 无障碍 / 子目录？**

| 维度 | chromium | firefox | webkit |
| --- | --- | --- | --- |
| `audit.py` 视口（**抽样**模式） | 320 / 375 / 390 / 430 / 768 / 1024 / 1440（**7**） | 375 / 768 / 1440（**3**） | 375 / 768 / 1440（**3**） |
| `interactions.py` 断言数（**引擎专用子集**） | **36**（9 个测试函数） | **19**（4 个） | **13**（2 个） |
| copy(13) / lightbox(21) / search_modal(14) / search_edge(29×2) / highlight(19) / shard(14) / modal_scroll(20) / contrast(4) / overflow / baseurl(81) | ✅ | ✅ | ✅ |
| 子目录 baseURL（`/` + `/blog/` + `/blog/sub/`） | ✅ | ✅ | ✅ |
| 无障碍（search modal 14 项 + contrast AA + tap-target） | ✅ | ✅ | ✅ |

> ⚠ 注意：`interactions.py` 的 chromium 子集**明显更大**（含 mobile 菜单、no-JS、键盘、TOC、灯箱等），
> firefox/webkit 只跑其中一部分 —— **不能**把 chromium 的 36 项当成"每个引擎都跑了 36 项"。

**C. 是否三引擎各自对"全部 286 页 × 7 视口"执行 `AUDIT_FULL=1` 全站审计？**

**❌ 未完成（且原口径不准）。**

- `AUDIT_FULL=1` 全站审计**只存在于** CI `release-full-audit` job，执行条件为
  **tag `v*` 推送或手动触发** —— 本特性分支推送**不触发**该 job。
- 即使触发，该 job 的视口是 **`320,375,768,1440`（4 个）**，**不是 7 个**；它确为三引擎全跑。
- push/PR 的 `browser-tests` 中 `audit.py` **未设 `AUDIT_FULL`** → 走**抽样**分支；
  7 视口配置**仅 chromium** 有。
- 结论：**"三引擎 × 全部页面 × 7 视口全站审计"从未发生**（历史与本轮均无证据）。
  最接近的是"三引擎 × 全站 × 4 视口"的 Release 全站审计，**本轮未在特性分支触发**。
- 开发方本地**只跑了抽样审计**（例：R4-007 修复证据为 chromium × 320/375/390/430，
  `3/7 PASSED(4 处问题)` → `4/4 PASSED, TOTAL PROBLEMS: 0`；本轮 R5-001 修复证据为
  chromium × 7 视口 `3/7 PASSED(24 处)` → `7/7 PASSED, TOTAL PROBLEMS: 0`）。

> 判定：**C 未完成**。不得以"抽样通过"或"CI 绿"替代全站全视口审计。

> `peaceiris/actions-hugo` 在运行时动态解析为当时最新稳定版，**不是固定版本号**，
> 因此**无法给出该条目的具体版本号/执行命令/退出码/原始日志**。两者不可混为一谈。
> 故所有文档统一更正为「**五版本固定矩阵**」（CI 另含 `latest` 动态条目，已在
