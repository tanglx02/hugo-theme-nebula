### 功能三 · 技术内容组件（4 个提交）

#### 3.1 Markdown 提示块（`9e8bca0`）— 零 JS

- 写法与 GitHub / Obsidian alert 一致：`> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]`，
  支持自定义标题 `> [!WARNING] 自定义标题`。
- 实现：`layouts/_default/_markup/render-blockquote.html`，纯 CSS，零 JavaScript、零第三方请求。
- 三种语言标题走 i18n（`alert.{note,tip,important,warning,caution}`），自定义标题优先。
- **未知类型不构建失败**：Hugo 内建解析会把**任意** `> [!FOO]` 塞进 `.AlertType`；本模板只放行 5 种已知类型。
- **版本兼容不降级**：blockquote hook 自 **0.148.0** 起被调用；**0.128.0** 静默忽略该文件，提示块退化为普通引用，构建 `exit 0`。
- 演示页：`exampleSite/content{,-en}/posts/alerts-and-callouts.md`

#### 3.2 标签页与步骤（`ea2a169`）— 服务端语义 + 零 JS

- `{{< tabs >}}` / `{{< tab "名称" >}}`：**导航条服务端渲染**，HTML 里导航与面板同时存在，不依赖 JS。
- `{{< steps >}}` / `{{< step >}}`：输出 `<ol class="steps">`，序号由 CSS counter 生成。
- 渐进增强 `assets/js/tabs.js`（WAI-ARIA APG）**按需加载**：仅当本页用了 `{{< tabs >}}` 才注入；普通页面多出字节数为 0。
- 无 JS 时"全部面板顺序展开 + 导航条隐藏"的默认态**完全由 CSS 保证**。
- **嵌套不丢内容**：占位符 token 机制（`util/nested-block.html` 登记 + `util/resolve-nested.html` 还原），
  修复"标签页里放步骤"时子组件 HTML 被父级 markdownify 丢弃（出现 `<!-- raw HTML omitted -->`）的缺陷。
- 演示页：`exampleSite/content{,-en}/posts/tabs-and-steps.md`

#### 3.3 文件树 / 徽标 / 按钮 / 折叠块（`9a820e7`）— 零 JS + URL scheme 校验

| shortcode | 说明 |
| --- | --- |
| `filetree` | 目录结构原样渲染；**不做 markdownify**（逐行纯文本）+ 显式 `htmlEscape`，文件名里的 `* _ [ ] & < > 引号`绝不解析、绝不注入 |
| `badge` | 行内标签，六变体；**变体白名单**，未知值归一 `default`（防 class 属性逃逸注入） |
| `button` | **URL scheme 白名单**；判定前剥离空白/控制字符（阻断 `java<TAB>script:` 绕过）；被拒时不输出 `<a>`，改 `<span.btn-disabled>` 且**不留 `href=""`**；仅外链加 `target=_blank rel=noopener` |
| `details` | 原生 `<details>`，零 JS，打印自动展开；**替代会被 goldmark 丢弃的裸 `<details>`** |

- 例：`button` 放行 `http/https/协议相对/mailto/tel/无 scheme 相对路径`，
  拦截 `javascript:/vbscript:/data:/file:/ftp:/空值`。
- 演示页：`exampleSite/content{,-en}/posts/content-components.md`

## 3. 修复的 Bug 清单（根因 / 修改 / 验证）

> 编号中 `BUG-R3-*` 为本阶段新发现并修复的缺陷；`BUG-P1-*` 为交付第一步顺带发现的既有缺陷。

### BUG-R3-001 · 语言键与 i18n 文件名不一致 → 0.128/0.148 全站 UI 文案**空串**（`8854565`）

- **现象**：`exampleSite/hugo.toml` 的 `defaultContentLanguage = 'zh'`，而主题 `i18n/` 下只有 `zh-CN.yaml`。
  Hugo 的语言键↔i18n 文件名是**大小写不敏感的精确匹配**、不做别名扩展；`locale` 字段仅在 **Hugo ≥ 0.162** 才作为 i18n 语言覆盖。
  于是 0.162+ 被 `locale='zh-CN'` 兜住看起来正常，**0.128 / 0.148 找不到 `i18n/zh.yaml` → 所有 UI 文案渲染为空**，
  且**构建不报错**（静默退化）。
- **修改**：`defaultContentLanguage` 改为 `zh-CN`，显式声明 `[languages.zh-CN]`。
- **验证（双层 + 反证）**：`tools/check_features.py` 第 8 节
  - 8a 静态：exampleSite 语言键必须命中 i18n 文件名；
  - 8b 行为：产物中 `NEBULA_I18N` 注入块的**每个值必须非空**（语言键不匹配的指纹就是"值全为空"）；
  - **反证**：把语言键改回 `zh` → 8a 变红；0.128 静默场景下 8b 变红。

### BUG-R3-002 · `[languages.*]` 顶层字段跨版本弃用（`74473bf`）

- **现象**：`label` 自 **0.112** 起弃用（**0.128.0 报 ERROR**）；`languageCode` 自 **0.158** 起弃用（新版 WARN）。
- **修改**：exampleSite 改用**唯一零告警形态**——根 `locale='zh-CN'` +
  `[languages.zh-CN]` 仅 `weight`/`contentDir` + 显示名放 `[languages.zh-CN.params].label`。
  `tools/lang-en.toml`、`lang-zh-TW.toml`、`multilingual.toml` 同步去除顶层 `label`/`languageCode`。
- **验证**：新增 `tools/check_lang_config.py`（60 项）五版本真实构建断言；
  静态侧 `check_features.py` **8c** 重写为 header-aware 扫描全部 `[languages.<key>]` 直接字段。

### BUG-R3-003 · `util/locale.html` 在 0.128.0 产出非规范 `og:locale`（`74473bf`）

- **现象**：0.128.0 上输出 `zh_cn`（地区子标签未大写、分隔符不规范）。
- **修改**：新增 **BCP47 规范化**（语言子标签小写、地区子标签大写），输出 `ll_CC` 形态。
- **验证**：`check_lang_config.py` L4 断言 `og:locale` 为规范 `ll_CC` 且与根级 `locale` 一致。

### BUG-P1-001 · 多语言站点 alias 页 `.Page` 为 nil 中断**整个构建**（`497670c`）

- **现象**：Hugo 会为**默认语言**额外生成 `/<defaultContentLanguage>/` 重定向页，该页**不附带目标 Page 对象**。
  `layouts/alias.html` 原写 `.Page.Title | default .Permalink`，`.Page` 为 nil 时 Go 模板
  `nil pointer evaluating page.Page.Title`，**中断整站构建**（不是渲染空标题，而是构建失败）。
- **实测版本差异**：0.128.0 / 0.148.0 / 0.162.0 **崩溃**；0.166.0 / 0.167.0 未复现（Hugo 改为跳过这类 alias）。
- **为什么 exampleSite 没暴露**：exampleSite 是单语言站点，不生成默认语言 alias 页；任何用户改成多语言即触发。
- **修改**：分步取值 + 显式判空，`.Page` 缺失时回退目标 URL。
- **验证**：五版本 × 多语言探针站点，构建 `exit 0`，alias 页 `<title>` 非空；`check_alias_pages.py` 11/11。
  **反证**：改回旧写法 → 该小节立刻变红（6 项 FAIL，total 111→85）。

### BUG-P1-002 · `{{ .Params.flag | default true }}` 布尔开关潜伏 Bug（`4af0c96`）

- **现象**：`default` 只认零值，而 `false` 即 bool 零值 —— 显式 `flag: false` 会**静默被忽略**（返回 `true`）。
  波及 `toc`/`comments`/`showDate`/`showLastmod`/`showTags`/`showRelated`/`showShare`/`showSeries`/`showNav`/`lightbox` 等全部开关。
- **修改**：新增 `layouts/partials/util/bool-param.html`，基于 `isset` 取值，**返回 dict 而非裸值**
  —— 因 Hugo 的 partial 返回值恒被包成 `template.HTML` 字符串，直接返回 `false` 会变成字符串 `"false"`（在任何 `if` 里都是真），反而更隐蔽。
- **验证**：五版本真机验证；`single.html` 全部开关改走该 partial。

### BUG-P1-003 · 裸 `<details>` 内容被 goldmark 静默丢弃（`9a820e7`）

- **现象**：`exampleSite/content{,-en}/posts/reading-experience.md` 里的裸 `<details>` 被 goldmark 丢弃，内容消失且不报错。
- **修改**：新增 `{{< details >}}` shortcode；演示页改用该 shortcode。

## 4. 开发中遇到的"坑"与教训（供测试方复验时重点关注）

> 这些是真实踩到的 Hugo / 工具链行为，很多**不是文档里写得清楚的**，也是本轮多个隐蔽 Bug 的来源。

### 4.1 Hugo shortcode 硬性规则

1. **不允许混用位置参数与具名参数**：`{{< details "标题" open="true" >}}` 构建失败
   （`Cannot mix named and positional parameters`）。已固化为回归断言 D9。
2. **词法层拒绝引号参数内的裸换行**：引号参数里换行 → `unterminated quoted string`。
   因此"用换行绕过 scheme 校验"**不可构造**；已固化为 D9b（断言构建必须失败）。
3. **写在行内 code span / 代码块内的 shortcode 也会被执行**：要"展示"短代码写法，必须用转义写法
   `{{</* ... */>}}`，否则演示页自身会构建失败（本轮演示页多次踩到）。
4. `{{% %}}` 在 `unsafe=false` 下会破坏嵌套输出 —— tabs/steps 只支持 `{{< >}}` 形式。
5. **即使自己在文档注释里写"只支持 `{{< >}}` 且不闭合"，也必须与实现一致**：`filetree` 原注释与实现自相矛盾，已更正为"块级短代码，必须成对闭合"。

### 4.2 Hugo 配置 / TOML 行为

6. **语言键 ↔ i18n 文件名**：大小写不敏感的**精确匹配**，不别名扩展；`locale` 仅 ≥ 0.158/0.162 作为 i18n 覆盖。
7. **`[languages.*]` 顶层弃用字段矩阵（实测）**：
   `label` 0.112 起弃用（0.128 ERROR）；`languageCode` 0.158 起弃用（新版 WARN）；`locale` 写在 `[languages.*]` 0.128 也报 ERROR；
   `weight`/`contentDir`/`params.*` 始终零告警。
8. **唯一零告警形态（形态 I）**：根 `locale='zh-CN'` + `[languages.zh-CN]` 仅 `weight`/`contentDir` + `[languages.zh-CN.params].label`。
9. **TOML "同名键遮蔽"陷阱（本轮新发现）**：`[languages.X]` 顶层 `label` 与 `[languages.X.params].label` 同名时，
   顶层 label 的弃用 ERROR 会被**静默吞掉** → **运行时告警不可全依赖，必须静态禁止**（8c 的价值所在）。

### 4.3 产物与 `--minify`

10. **Hugo `--minify` 会去属性引号**（`class="tabs"` → `class=tabs`）、**压 CSS 空白**（`.a > b` → `.a>b`）。
    → 所有产物正则必须写成"**引号可选 + 空白归一**"，否则生产构建（`--minify`）会**假红**。
11. Hugo 会在 Render Hook 输出之后**再追加一个换行** → 模板文件**末尾不得有换行符**，否则每个引用块后多一个空行
    （用 md5 逐候选穷举确认）。
12. **goldmark 危险 scheme**：markdown 链接里的 `javascript:`/`vbscript:`/`data:text/html`/`file:` 会被清空为 `href=""`。

### 4.4 Go 模板 / partial

13. **Hugo partial 返回值恒为 `template.HTML` 字符串** → 布尔 helper 必须返回 dict（调用方取 `.value`）。
14. `{{ .Params.flag | default true }}` 在 `flag:false` 时返回 true（见 BUG-P1-002）。

### 4.5 环境 / 工具链陷阱

15. **heredoc + MSYS 路径转换会损坏 `\n` → `/n`**：用 `chr()` 构造字符串规避。
16. **沙箱批量删除保护** `[SAFE_DELETE_BULK_CONFIRM_REQUIRED]`（>50 文件需显式放开）；
    **后台任务不继承该放开**（本轮后台跑 `check_lang_config` 曾被中断，改前台执行）。
17. **`os.remove` 被重定向回收站会失败** → 改用 `copytree(ignore=)` 或 `--cleanDestinationDir`。
18. **`exampleSite/hugo.toml` 是 CRLF 文件**；`.hugo_build.lock` 访问拒绝需删锁重试。
19. **`--themesDir` 不能用符号链接 / junction**（0.128 / 0.148 不解析）。
20. **`$PWD` POSIX 路径给 Windows Hugo 会致 `--config` 第二文件不生效** → 用 Windows 绝对路径。
21. **`EXIT=$?` 紧跟管道会取到 head 退出码** → 须用 `${PIPESTATUS[0]}`。

## 8. 建议测试方重点验证的项

1. **隐蔽退化类**（最易漏）：0.128/0.148 上**全部 UI 文案是否为空**（BUG-R3-001）；多语言站点 alias 是否中断构建（BUG-P1-001）。
2. **安全边界**：`button` 对 `javascript:`/`java<TAB>script:`/空值的拦截、被拒时是否**不留 `href=""`**；外链是否带 `noopener`。
3. **内容不丢**：裸 `<details>`、标签页中嵌套步骤、tabs 无 JS 展开 —— 是否出现 `<!-- raw HTML omitted -->` 或 token 残留。

6. **`--minify` 容错**：生产构建下断言是否仍全绿（不得因去引号/压空白假红）。
7. **布尔开关**：显式 `showDate: false` / `comments: false` 等是否**真的**生效（BUG-P1-002）。
